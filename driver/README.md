# Виртуальный аудиокабель (папка для пакета драйвера)

Положите сюда **подписанный** пакет WDM-драйвера виртуальной звуковой карты:

```
driver\
  AmpCastCable.inf
  AmpCastCable.sys
  AmpCastCable.cat
```

Инсталлятор (`installer\AmpCast.iss`) сам заметит файлы, добавит галочку
«Установить AmpCast Cable» и выполнит:

```
AmpCast.exe --install-driver "<app>\driver\AmpCastCable.inf" "Root\AmpCastCable"
```

Hardware ID (`Root\AmpCastCable`) должен совпадать с тем, что указан в секции
`[Models]` вашего `.inf`. Если имена другие — поменяйте `CableInf` / `CableHwId`
в начале `AmpCast.iss`.

## Откуда взять драйвер

Драйвер режима ядра на Windows 10/11 x64 загрузится только с подписью Microsoft.
Варианты:

1. **Свой драйвер** на основе примера Microsoft *SYSVAD* (Windows-driver-samples,
   лицензия MIT): переименовать устройство в «AmpCast Cable», собрать в WDK и
   подписать через **attestation signing** в Microsoft Partner Center
   (нужен EV-сертификат подписи кода). Самый «чистый» путь для бесплатной
   программы.
2. **Готовый open-source драйвер с подписью**, лицензия которого разрешает
   распространение в составе вашего инсталлятора. Перед включением проверьте
   лицензию и наличие подписи Microsoft у `.cat`.
3. **VB-CABLE** (VB-Audio) — бесплатен для пользователей, но встраивать его в
   свой инсталлятор можно только по лицензии VB-Audio. Без лицензии просто
   попросите пользователя установить его отдельно: AmpCast сам найдёт
   устройство «CABLE Input» и выберет его.

Пока папка пустая, инсталлятор собирается без кабеля, а AmpCast умеет
работать с любым уже установленным виртуальным кабелем.
